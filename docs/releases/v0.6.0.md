A feature and fix release for *The Legend of Zelda: Ocarina of Time* for Nintendo Switch 2 (game version 1.1.1):
smoother play, lower memory use, correct lighting on characters, a new HDR, Xbox, PlayStation and keyboard button
prompts, and many crash and freeze fixes. **No game files are included**: the setup builds the game on your PC from your own dump.

## Install or update

- **Already have 0.5.0:** start the launcher; it offers 0.6.0, updates itself and rebuilds the game from the files it
  already has, without the dump. This update compiles the game again for your processor, so it takes about as long as
  the first build (10 to 25 minutes, once); later updates compile only what changed. The shaders are prepared again
  too.
- **New install:** download **`NX2navi-Setup-0.6.0.exe`** below, put it next to your `.nup` dump of the game and start
  it. Windows SmartScreen warns on the first start because the setup is not signed: choose *More info* and *Run
  anyway*. The launcher builds the game (10 to 25 minutes, once), prepares every shader and starts it.

**Requirements:** Windows 10 or 11; an x86-64 CPU with SSE4.2; 16 GB of RAM; about 30 GB free for the game and 1.5 GB
for the launcher; a GPU with Vulkan 1.3, `VK_EXT_external_memory_host` and `VK_EXT_mesh_shader` (current NVIDIA and AMD
cards).

## New

- Xbox, PlayStation and keyboard and mouse button prompts, and a PlayStation choice for the button layout. The setup
  carries the button art and the build draws the prompts on your PC; the keyboard prompts follow your key bindings
  ([controls.md](../controls.md)).
- A new HDR: the game's picture tone mapped to your display's peak, with exposure, highlights, shadows, contrast,
  saturation and gamma in the menu, or the game's own native HDR. A change of desktop resolution, layout or HDR in
  fullscreen is followed.
- Pick the monitor the game opens on (`monitor`, `--monitor`) and the sound output device (`audio_device`,
  `--audio-device`); the game opens straight in fullscreen when fullscreen is on.
- The game's microphone input uses your default microphone (`microphone = 0` turns it off).
- Your Discord status shows "Playing NX2navi" with your play time while the game runs. It is on by default; turn it
  off in the game's settings menu (Game tab) or in the launcher's Settings (Discord Status).
- DualShock 3 controllers on Windows, read directly when no driver presents them (off by default: `ds3 = 1`).
- A 1080p game resolution.
- NVIDIA DLSS Frame Generation on GeForce RTX 40 and 50 GPUs, with DLSS on: the setup now carries what it needs, and
  it is paced with Reflex so it does not halve the frame rate.
- DLAA runs with native HDR too.
- The frame limit can be handed to RivaTuner Statistics Server where it runs.
- The launcher shows the shader preparation moving, with a time estimate that follows its pace, and preparation
  translates about twice as fast. Every one of the game's 42,177 shader programs now translates.
- Import Saves can import a single save slot into its own slot and keep the rest of the save.

## Fixed

- Link and the other characters are no longer drawn too dark: the game's GPU queues replay in the order their events
  allow.
- The white specks in foliage are gone, and so are trees that flickered or stretched into columns.
- A running Link no longer trails with DLSS or frame generation; widescreen pictures render at the DLSS mode's real
  share, and the DLSS mode's render scale applies as soon as it is picked.
- The intro's narration no longer doubles and the dream shows correctly at high refresh rates (movies hold 60 fps).
- Memory: the title screen no longer climbs to 30 GB; released textures and idle VRAM copies are freed when video or
  system memory runs low; very large compute shaders are built in the background instead of stalling a frame.
- Shader and pipeline stutter: fewer first-encounter pauses, entering a new area no longer waits for its pipelines one
  at a time, and `pipeline-cache.bin` is capped (512 MB by default) so it no longer grows without end.
- DLSS Ultra Performance upscales to the picture's size instead of to the first pass wider than the scene.
- Movies play at their 60 fps instead of in slow motion.
- A shader conversion of signed integers to floats is translated correctly.
- Less copying of the GPU's writes back to the game's memory.
- With the performance log on, the game no longer hitches every ten seconds.
- Kokiri Forest runs faster.
- The audio renderer no longer goes silent or hangs on edge values, and menu sounds no longer click when restarted.
- Windows' switched mouse buttons are followed; the window opens inside the screen and fullscreen comes back when the
  window is raised; the game closes down properly when Windows shuts down.
- A crash when the game's microphone stream could not open is gone.
- The game's window and taskbar button show Navi, and starting the game from the launcher no longer opens an empty
  console window beside it.
- The game keeps presenting after a failed present, and only one game runs per profile at a time.
- Saves: Import Saves and Quit keep saves safe, a linked profile folder keeps working, and save writes check their
  sizes.
- Mods are found under this game's title id (0400486024DEC000), a mod folder that cannot be listed is logged, and one
  cheat the lifter cannot take is marked unsupported instead of failing them all.
- The launcher: a damaged `.nup` is reported instead of hanging, a rollback says why, a broken self-update can be
  repaired by the setup, uninstall leaves a game folder kept inside the launcher's folder, and settings values that
  would change on reading back are quoted.

## Known issues

- The first visit to an area after an install can pause while the graphics driver builds what it has not seen.
- Machines with 16 GB of RAM can run out of system memory in Hyrule Field.
- Integrated AMD GPUs can fail at the title screen (their host memory heap is too small for the game's memory).
- A rare crash in the game's particle code.

## For builders

- `tools/make_game.py` builds the game natively on Linux, and the build kit can be packed as an AppImage. The launcher
  and the setup are Windows only.
